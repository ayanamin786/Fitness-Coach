# AI Fitness Coach — Multi-Page Edition

Flow:
1. Open `index.html`
2. New users → Sign Up
3. Existing users → Log In
4. Successful login → `dashboard.html`
5. Sidebar navigates between separate pages:
   - Dashboard
   - BMI
   - Calories
   - Workout
   - Nutrition
   - Habits
   - Progress
   - AI Coach
   - Admin Center
6. Logout returns to login.

Authentication is a frontend/localStorage demo only; it is not secure production authentication.
